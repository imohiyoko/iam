# 0005. RSA を自前の鍵で使わず、耐量子暗号を併用する

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 9.1〜9.3

## 背景

RSA は将来弱くなるおそれがある。また楕円曲線暗号（ECC）も量子計算機で破られるため、ECC だけでは耐量子にならない。

## 決定

- 自前の鍵では RSA を使わない。現行の最低ラインは ECC
- 耐量子性は ML-KEM / ML-DSA で確保する。TLS は X25519MLKEM768 ハイブリッド、トークン署名は ML-DSA-65 と ES256 を RP ごとに使い分ける（RFC 9964）
- 共通鍵・ハッシュは AES-256-GCM、SHA-256、HMAC-SHA-256、argon2id
- 鍵とアルゴリズムは kid 付きで管理し、切り替えられるようにする（暗号アジリティ）

## 結果

- OIDC Discovery が必須とする RS256 を提供しないため、厳密には仕様に適合しない。RS256 しか扱えない RP とは連携できない
- ML-DSA の署名は大きい（約3.3KB）。アクセストークンを不透明にする理由の1つになった（0021）

## 検討した代替案

- RSA を併用する（方針に反する）
- ECC のみ（耐量子にならない）
