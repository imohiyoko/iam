# 0008. ホスト型ログイン画面と公開 API の2本立てにする

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 2.5

## 背景

手軽に使いたいアプリと、自前の UI を作りたいアプリの両方がある。ログイン画面の作り込みにはこだわらない。

## 決定

- ホスト型ログイン画面（OIDC でリダイレクト）と、ヘッドレスの公開 API の両方を提供する
- 正は公開 API とし、ホスト型ログイン画面も公開 API の上に作る
- 公開 API は `/v1` でバージョニングし、OpenAPI で定義する。管理 API とは分離する

## 結果

- 両者の挙動がずれない
- 別ドメインのアプリから使う場合の passkey の RP ID（Related Origin Requests）、CORS、CSRF への対応が必要

## 検討した代替案

- どちらか一方のみ
