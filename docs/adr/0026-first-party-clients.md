# 0026. 連携先は当面ファーストパーティのみとする

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 5.5

## 背景

外部の開発者に「このサービスのアカウントでログイン」を提供する（サードパーティへの開放）には、同意画面や審査などが必要になるが、現時点で用途が想定できない。

## 決定

- 連携先はホスト先が管理 API で登録したアプリのみとし、同意画面は出さない
- 動的クライアント登録は持たない
- 将来に備え、クライアントに `trust_level` を持たせておく

## 結果

- 実装と運用が単純になる
- サードパーティを開放する場合は、フィーチャーとして追加する

## 検討した代替案

- 最初からサードパーティに対応する
