# 0035. ID（ユーザー名）でのログインには2要素目を必須にする

- 状態: 置き換え: 0037
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 4.1
- 一部置き換え対象: [0032](0032-username-password-signup.md)

## 背景

0032 では、ID とパスワードだけのログインを許し、拒否するかどうかは設定に任せていた。しかし ID はメールアドレスと違って存在を隠せず（登録時に使用中かどうかを返す必要がある）、推測と総当たりの対象になりやすい。

## 決定

- ID とパスワードの1要素だけでのログインは許可しない。ID でログインする場合は、必ず passkey または TOTP の2要素目を求める
- 登録時に2要素目も登録させ、登録し終えるまでアカウントを作らない
- これは設定で外せない（0033 の例外。セキュリティ不変条件として扱う）
- 2要素目が必須なので、パスワードの最低長の既定値は8文字とする

## 結果

- ID によるログインの安全性を、設定に左右されずに保てる
- 2要素目を用意できない利用者は、ID ではなくメール・OAuth・passkey でログインすることになる

## 検討した代替案

- 設定で拒否するかどうかを選ぶ（0032。緩い設定で運用されると、総当たりに弱いアカウントが生まれる）
