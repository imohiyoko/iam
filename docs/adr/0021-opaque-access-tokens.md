# 0021. アクセストークンは不透明トークンにする

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 5.1

## 背景

JWT のアクセストークンは、失効・停止を有効期限まで反映できない。また ML-DSA の署名で 4KB を超え、Cookie やヘッダーの制限に近づく。

## 決定

- アクセストークンは不透明トークンとし、リソースサーバーはイントロスペクション（RFC 7662）で確認する
- ID トークンは OIDC の仕様どおり JWT とする

## 結果

- 失効・停止を即時（0024 の上限内）に反映できる
- リソースサーバーは IAM への問い合わせが必要になる（短時間のキャッシュは可）

## 検討した代替案

- JWT のアクセストークン
