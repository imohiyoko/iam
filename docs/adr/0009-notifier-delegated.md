# 0009. メールなどの配送は外部に任せる

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 2.4

## 背景

メール配送の仕組みは IAM の本質ではなく、ホスト先ごとに使いたい手段が違う。一方で、個人で開発する間は配送の仕組みがないと開発しにくい。

## 決定

- IAM は「何を誰に通知すべきか」を決めて渡すところまでを担い、配送は外部に任せる
- 同梱アダプタは Webhook と SMTP リレー（SES・Postfix など任意の SMTP サーバーに渡すだけ）
- 開発用アダプタ（標準出力・受信箱画面）は開発ビルドにだけ含める。メールの見た目の確認には Mailpit を使う

## 結果

- 配送の信頼性・到達率は外部の仕組みに依存する
- 通知は outbox 経由で確実に渡す

## 検討した代替案

- IAM が独自にメールを配送する
