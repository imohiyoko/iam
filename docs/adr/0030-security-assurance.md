# 0030. 第三者のレビュー不足を、機械による検証と外部の基準で補う

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 13

## 背景

大枠を個人と AI で作るため、第三者のレビューが入りにくい。

## 決定

- 暗号とプロトコルは実績のあるライブラリに任せ、自前のコードを減らす
- OIDC・WebAuthn の適合試験、依存の脆弱性検査、静的解析、ファジングを CI で回す
- セキュリティ不変条件を列挙してテストと対応させる
- AI が書いたコードは、別のエージェントにセキュリティ観点でレビューさせ、重要な部分は人のレビューを必須にする
- 第三者監査を受けるまでは実験段階と明記する

## 結果

- v1.0 の条件に、適合試験の合格と第三者監査の完了を含める
