# 0006. 外部の RS256（passkey 等）は受け入れ、警告の対象にする

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 9.4

## 背景

一部の Windows Hello など、RS256 しか使えない passkey の認証器がある。拒否すると、それらの利用者が passkey を使えない。

## 決定

- passkey は ES256 / EdDSA / RS256 を受け入れる。登録時の優先順は ES256 → EdDSA → RS256
- RS256 は警告（`passkey_alg_rsa`）の対象とし、拒否したい場合は警告のアクション設定で行う（0007）
- 外部の公開鍵の検証であり、自前で RSA 鍵を持つわけではないので 0005 には反しない
- OAuth プロバイダの ID トークン（RS256）は、TLS で直接受け取ることで署名検証を代替する

## 結果

- 互換性を保ちつつ、利用者に改善を促せる
- 当初の passkey 専用設定（`allow_rs256`）は廃止し、共通の警告の仕組みに統合した

## 検討した代替案

- RS256 を拒否する（互換性を失う）
