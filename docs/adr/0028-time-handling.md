# 0028. 時刻は UTC で扱い、タイムゾーンは日付入力の変換にだけ使う

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 2.7

## 背景

有効期間・停止・Quota・セッションなど、多くの判定が時刻に依存する。

## 決定

- 保存と API の値はすべて UTC。表示の変換はホスト先・クライアントが行う
- realm の既定タイムゾーンを初期設定で指定し、Org で上書きできる。日付だけの入力を時刻に変換するときにのみ使い、使ったタイムゾーンを記録する
- 時刻の取得は Clock ポートに統一し、テストでは偽の時計を使う
- インスタンスと DB の時刻のずれを監視する

## 結果

- 判定が一貫し、テストしやすい

## 検討した代替案

- ローカル時刻で保存する
