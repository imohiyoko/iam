# 0087. 証明済みのドメインは定期的に TXT を確かめ直し、猶予の間ずっと無ければ証明を外す

- 状態: 承認
- 日付: 2026-10-31
- 関連: [design.md](../design.md) 11.3、[0075](0075-org-domain-verification.md)、[0076](0076-org-managed-users.md)、[0077](0077-org-sso.md)

## 背景

ADR 0075 では、一度証明したドメインは owner か運営者が消すか Org を消すまで証明済みのまま残していた（確かめ直しは後に回した）。
ドメインを手放した・失効した・TXT を消した後も、その Org は管理ユーザーの登録（ADR 0076）や Org 専用 SSO の振り分け（ADR 0077）で
ドメインを使い続けられる。ドメインを取り直した別の持ち主は、そのドメインを証明できない（`domain_taken`）。

## 決定

- 証明済みのドメインは、最後に確かめた時刻（`checked_at`）から `org_domains.recheck`（既定 1 日、0 で確かめ直さない）を過ぎたら
  `_iam-challenge.<domain>` の TXT を引き直す。対象は1時間ごとに探し、1回に `outbox.batch` 件まで確かめる。確かめていないものと古いものが先
- TXT が見つかれば何もしない（見つからなくなった時刻を消す）
- 見つからない（名前が無い・値が違う）ときは、初めてなら `org_domains.missing_since` に時刻を残して `org.domain.missing` を出す。
  `missing_since` から `org_domains.grace`（既定 7 日）を過ぎてもまだ無ければ証明を外し（`pending` に戻る）、`org.domain.unverified` を出す
- DNS の障害は猶予に数えない。`checked_at` を進めて次の間隔で引き直し（障害の続くドメインが1回分を占めないため）、
  `missing_since` があれば前に確かめた時刻からの分だけ後ろへずらす
- DNS はトランザクションの外で引き、書くときに行が同じ（ID とトークンが同じで、まだ証明済み）ことを確かめる。複数のインスタンスで動いても
  結果は同じになる
- 証明を外しても、既に管理ユーザーになった人や作った connection はそのまま。新しく管理ユーザーにすること・SSO のドメインでの振り分けは、
  証明し直すまでできない。外れたドメインは owner が TXT を置き直して `:verify` すれば戻る。別の Org も証明できるようになる

## 結果

- 所有が続いていないドメインに証明が残らない。取り直した持ち主は猶予の後に証明できる
- 一時的な DNS の設定の誤りでは外れない（猶予の間に直せば `missing_since` が消える）。`org.domain.missing` を SIEM で拾えば owner に知らせられる
- 証明済みのドメインの数だけ、1日に1回の DNS の問い合わせが増える

## 検討した代替案

- 見つからなかったら即座に外す：DNS の移行や設定の誤りで、管理ユーザーの登録や SSO が突然止まる
- 続けて見つからなかった回数で外す：間隔を変えると猶予の長さが変わり、運営者に分かりにくい。時刻で持つ方が設定と合う
- 外すときに管理ユーザーも個人ユーザーに戻す：本人の同意で管理下に入った人を、DNS の状態だけで動かすのは影響が大きい。運営者・owner の判断に残す
