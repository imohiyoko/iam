# 0010. 機能をフィーチャー単位で取捨選択できるようにする

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 2.6, 11

## 背景

拡張性は最大限確保したい。一方で、レイテンシが過剰になる機能や使わない機能は捨てて最適化したい。

## 決定

- 機能をフィーチャー単位にまとめ、オン・オフできるようにする
- オフにした機能はコストゼロにする。処理経路は起動時に組み立て、リクエストごとに分岐しない
- フィーチャーごとにレイテンシを計測し、捨てる判断の材料にする
- ホットパス（トークン検証、認可判定）には同期の外部呼び出しを置かない

## 結果

- 小さな構成から大きな構成まで同じコードで対応できる
- フィーチャー間の依存関係の管理が必要になる

## 検討した代替案

- 全機能を常に有効にする
