# 0027. セッションの寿命はホスト → realm → Org の階層で設定する

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 5.4

## 背景

セッションの寿命の要件はホスト先や Org ごとに違う。

## 決定

- ホスト先が既定値と上限を決め、realm と Org が上限の範囲内で上書きする
- 実際の値は、セッションの realm と active な Org の設定で決まる。Org の切り替えで寿命を超える場合は再認証を求める
- 管理者のセッションとサービスアカウントのトークンには、より短い既定値を設ける

## 結果

- Org ごとの要件に応えつつ、ホスト先が全体の安全性を保てる

## 検討した代替案

- 全体で1つの値のみ
