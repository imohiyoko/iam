# 0029. 監査ログはホスト先が決めた保持期間で削除し、ハッシュチェーンはチェックポイントで切り詰める

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 6.5

## 背景

監査ログはハッシュチェーンで改ざんを検知するが、個人情報をできるだけ持ちたくないため、一定期間後には消したい。

## 決定

- 保持期間（既定90日）はホスト先が設定する。長期保管は SIEM に任せる
- チェーンは先頭から切り詰め、最後に削除したイベントのハッシュをチェックポイントとして残す
- チェックポイントは SIEM にも送り、外部の記録と突き合わせられるようにする

## 結果

- 保持期間を過ぎたログは IAM からは参照できない

## 検討した代替案

- 永久に保持する（個人情報を持ち続けることになる）
