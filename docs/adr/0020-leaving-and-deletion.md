# 0020. 退会の可否はユーザーの種類で決め、削除は猶予期間と crypto-shredding で行う

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 4.10

## 背景

Org からの退会を本人に許すべきか、全体からの退会（アカウント削除）をどう扱うかを決める必要がある。

## 決定

- 個人ユーザーの共有 Org からの退会は常に許可し、恒久的には妨げられない。Org 管理ユーザーは所有元から本人では抜けられない
- Org には常に1人以上のオーナーが必要
- 退会は Membership の有効期間の終了として表す
- アカウント削除は猶予期間（既定30日）の後、データ鍵の削除で個人情報を読めなくする。ID は墓標として残す。legal hold で保留できる

## 結果

- 本人の意思で関係を断てることを保証できる
- ホスト側の事情（引き継ぎ待ち）による一時的な保留はフックで行う

## 検討した代替案

- Org のポリシーで退会を禁止できるようにする（本人が関係を断てなくなる）
