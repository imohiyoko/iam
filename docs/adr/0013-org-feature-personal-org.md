# 0013. Org をフィーチャーにし、有効時は個人 Org を自動作成する

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 11.13

## 背景

Org が不要な用途（個人向けアプリ、単一組織のツール）でも使えるようにしたい。一方で Org を使う場合、「どの Org にも属さない状態」があると判定が複雑になる。

## 決定

- Org そのものをフィーチャーにする。オフなら認証だけで動き、認可は realm 全体の範囲で行う
- オンなら全ユーザーに個人 Org を作り、常に何らかの Org の文脈でログインする
- 個人 Org はメンバーが本人のみで、ユーザーと一体

## 結果

- Org の決定と認可の判定が単純になる
- 後から Org を有効にする場合、既存の全ユーザーに個人 Org を作る準備処理が要る

## 検討した代替案

- Org に属さない状態を許す（判定が複雑になる）
