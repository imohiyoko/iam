# 0022. 拒否理由は本人確認の後にだけ返す

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 4.9

## 背景

拒否理由のコード（停止中など）をログイン画面で返すと、パスワードを知らない人にもアカウントの存在と状態が分かってしまう。

## 決定

- 本人確認の前は、理由を区別しない `authentication_failed` のみを、同じ応答・同じ応答時間で返す
- 本人確認の後は、本人に拒否理由のコードを返す。管理 API では権限の範囲内で詳細を返す
- マジックリンク・新規登録・復旧の要求は、アカウントの有無を区別しない応答にし、事情はメールの中で伝える

## 結果

- アカウントの列挙を防げる
- 本人以外にはエラーの原因が分かりにくくなる

## 検討した代替案

- 常に理由を返す（列挙が可能になる）
