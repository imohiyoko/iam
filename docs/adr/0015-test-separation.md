# 0015. フィーチャーのテストと DB のテストを切り離す

- 状態: 承認
- 日付: 2026-10-25
- 関連: [design.md](../design.md) 12

## 背景

フィーチャーの組み合わせ × DB アダプタをすべてテストすると組み合わせが爆発する。

## 決定

- フィーチャーのテストはインメモリの参照実装に対して行う
- DB のテストは、Repository の契約テストを各アダプタに対して実 DB で行う。各アダプタは別の Go モジュールにする
- 参照実装も契約テストを通す
- 認証基盤として、並行性・realm の分離の契約テストを必須にする

## 結果

- 掛け算が足し算になる
- 契約テストの網羅性が品質を左右する

## 検討した代替案

- 全組み合わせをテストする
